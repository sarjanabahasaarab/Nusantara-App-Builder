# Live Logcat Viewer

## Fitur Logcat
- **Privasi Lokal**: Log perangkat dibaca langsung dari ADB lokal tanpa dikirim ke server pihak ketiga.
- **Tingkat Log (Log Levels)**:
  - `V`: Verbose
  - `D`: Debug
  - `I`: Info
  - `W`: Warning
  - `E` / `F`: Error & Fatal Crash
- **Penyaringan**: Cari berdasarkan tag komponen (misal: `NusantaraApp`, `ActivityTaskManager`) atau teks pesan crash.
